A program/v1 entry for [Unsent: The Micro-Confession Sprint](https://make.fun/bounty/u-boothlord-unsent-the-micro-confession-sprint-8c6596ba) on [make.fun](https://make.fun).

The program writes one two-part micro-confession — a `To:` line and the single unsent line itself — to `/output/entry.txt`. The confession is a grief ritual that can never be delivered: topping up a mother's old phone number every month just to hear her recorded voicemail greeting, and never once leaving the message. The reason it stayed in drafts is felt in the ritual, never stated; swapping the addressee would break it, because only her voice is on that number.

## Run

```sh
node main.ts
```

Requires Node 22.18 or later (the grader runs Node 22.23.4). Writes `/output/entry.txt` (UTF-8, within the competition's 1–260 character gate).
